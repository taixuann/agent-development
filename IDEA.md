**IDEA.md**

A lightweight, open-source Python framework for building, testing, and deploying autonomous AI agents with minimal boilerplate.

- Provide a declarative API for defining agent goals, tools, and memory in under 50 lines of code
- Include a built-in sandboxed execution environment for safe tool use (file I/O, shell, browser)
- Ship a visual debugger that traces agent reasoning steps, tool calls, and token usage in real time
- Support pluggable LLM backends (OpenAI, Anthropic, local models) via a unified interface
- Offer one-click deployment to serverless platforms (Lambda, Cloud Run) with built-in observability
